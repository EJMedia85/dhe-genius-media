How authorization works

1. Register
This browser/device sends a registration request to DGM.
2. Admin approval
DGM Admin opens Admin → DGM Bridge and chooses Approve or Deny.
3. Authorization
Once approved, this page receives a signed Bridge session token.
4. Pair
An approved host can create a temporary pairing code for an approved client.
